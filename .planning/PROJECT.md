# document-scanner-67

## Vision
A privacy-first, open-source document scanner web application built with Next.js and shadcn/ui. 

## Technical Constraints
- **Offline-First:** All processing must happen entirely in the browser on the client side. No backend APIs, no cloud databases.
- **Styling:** Strict use of Tailwind CSS and the existing Shadcn UI components in the `components/ui/` directory.
- **Language:** Strict TypeScript.
